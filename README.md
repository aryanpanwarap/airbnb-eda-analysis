# Airbnb Exploratory Data Analysis (EDA)

## 📌 Problem Statement
The goal of this project is to analyze Airbnb listing data to understand
pricing patterns, availability trends, and factors affecting rental prices.

---

## 📂 Dataset
- Source: Airbnb open dataset
- Records: 40,000+ listings
- Key features: price, location, room type, availability

---

## 🧹 Data Cleaning
- Removed missing and duplicate values
- Converted price column to numeric format
- Handled outliers to avoid skewed analysis

---

## 🔍 Exploratory Data Analysis
- Distribution of prices across listings
- Comparison of room types and their average prices
- Location-wise pricing and availability trends

---

## 📈 Key Insights
- Entire homes are significantly more expensive than private rooms
- Listings in central locations have higher prices and occupancy
- Availability impacts pricing behavior

---
